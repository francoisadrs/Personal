# Profils par instrument — composantes & pratique variable

Le découpage piano de Casares sépare **main gauche / main droite / mains
ensemble**. C'est un cas particulier d'un principe général : **décomposer le jeu
en couches indépendantes** que le cerveau peut automatiser séparément avant de
les coordonner. Ce fichier donne, par famille d'instrument :

- les **composantes** (= options du champ `Composante` de la base Notion, voir
  `notion-contract.md`) ;
- des **techniques** typiques (champ `Techniques`) ;
- des idées de **pratique variable** (Gebrian, Appendice C) à activer une fois
  un passage joué proprement.

> Règle : toujours finir par une composante « **Ensemble / Tutti** » qui réunit
> les couches. Pour les instruments monophoniques sans « mains » distinctes, les
> composantes sont des *dimensions* (notes/doigtés, articulation, souffle…)
> plutôt que des membres.

---

## Clavier — piano, clavecin, orgue, synthé
- **Composantes** : `Main gauche`, `Main droite`, `Mains ensemble`.
  (Orgue : ajouter `Pédalier`, puis `Tutti`.) Si une main porte 2 voix, on peut
  créer une composante par voix.
- **Techniques** : Gammes, Arpèges, Accords, Trilles, Legato, Staccato, Sauts,
  Voix multiples, Pédale, Ornements.
- **Pratique variable** : mains séparées (même tardivement) ; alterner mesure
  MD / mesure MG en continu ; jouer la partie d'une main avec l'autre ; mains
  croisées / décroisées ; écarter les mains d'une octave ; changer la main qui
  « mène » ; mélodie à un seul doigt + poids du bras ; inverser mélodie /
  accompagnement ; jouer les pouces seuls en rythme ; varier la pédale (sans
  pédale, 1-2 s autorisées, film léger) ; varier le registre ; varier où l'on
  regarde.

## Cordes frottées — violon, alto, violoncelle, contrebasse
- **Composantes** : `Main gauche` (justesse, doigtés, démanchés, vibrato),
  `Archet / Main droite` (coups d'archet, articulation, distribution, cordes),
  `Ensemble` (coordination des deux). (Gebrian est altiste — référence directe.)
- **Techniques** : Démanchés, Justesse, Vibrato, Coups d'archet (détaché,
  legato, spiccato, martelé), Doubles cordes, Cordes à vide, Changements de
  corde, Trilles.
- **Pratique variable** : varier tempos / coups d'archet / patterns de liaison ;
  travailler l'intonation note tenue + drone ; pizz pour isoler la MG ; cordes à
  vide pour isoler l'archet ; rythmes variés sur les traits rapides.

## Bois & cuivres — flûte, clarinette, hautbois, basson, sax, trompette, cor…
- **Composantes** : `Doigtés / Notes`, `Articulation / Langue`,
  `Souffle / Air & soutien`, `Ensemble` (tout coordonné).
- **Techniques** : Justesse, Souffle/soutien, Articulation (simple/double/triple
  langue), Legato, Staccato, Registres, Trilles, Sauts d'intervalle.
- **Pratique variable** (Appendice C) : souffler le rythme dans l'instrument
  sans son (air + langue seuls) ; bourdon sur l'embouchure (cuivres) ; chanter
  sur « da/ta » ; jouer un passage grave/aigu dans une octave plus confortable ;
  varier les syllabes d'articulation ; flatterzunge ; jouer chaque note articulée
  uniquement par l'air (sans langue).

## Voix
- **Composantes** : `Texte / Diction`, `Mélodie / Justesse`,
  `Souffle / Soutien`, `Ensemble`.
- **Techniques** : Souffle, Justesse, Legato, Diction, Registres/passaggio,
  Ornements, Dynamique.
- **Pratique variable** : parler le texte en rythme ; vocaliser sur voyelle
  neutre puis ajouter le texte ; chanter sur solfège / noms de notes ; varier
  nuances et couleurs ; pratique mentale audiée.

## Guitare / instruments pincés (luth, harpe)
- **Composantes** : `Main gauche` (doigtés/positions), `Main droite`
  (pince/butée, plan de jeu), `Ensemble`. (Harpe : ajouter `Pédales`.)
- **Techniques** : Arpèges, Accords/barrés, Legato (hammer/pull), Staccato,
  Déplacements de position, Pince/butée, Étouffements.
- **Pratique variable** (harpe, Appendice C) : œuf-shaker dans une main pour le
  tempo en jouant de l'autre ; chanter une ligne en jouant l'autre ; jouer sans
  les pédales puis pédales seules en rythme ; jouer détaché là où l'on lie.

## Percussions à claviers / batterie
- **Composantes** : par membre (`Main gauche`, `Main droite`, `Pieds`) puis
  `Ensemble` (4 membres). Pour mailletophones à 4 baguettes : par main / par
  paire de baguettes.
- **Techniques** : Indépendance, Sticking, Roulements, Déplacements, Dynamique,
  Coordination.
- **Pratique variable** : membres séparés ; varier le sticking ; varier tempos
  et nuances ; un membre en ostinato pendant qu'un autre varie.

---

### Comment l'utiliser
1. Identifier la famille de l'instrument du morceau.
2. Reprendre la liste des **composantes** → ce sont les sous-tâches de chaque
   passage dans Notion.
3. Reprendre les **techniques** pertinentes → champ `Techniques` (multi-select).
4. Garder les idées de **pratique variable** pour la phase *Fluide → Maîtrisé*
   (le planner les injecte, cf. `weekly-planning.md`).

Si l'instrument n'est pas listé : appliquer le principe — séparer les couches
indépendantes (membres, ou dimensions notes/articulation/souffle), automatiser
chacune, puis une composante « Ensemble » qui coordonne.
